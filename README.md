# 晴湾钓鱼 · 制作说明

版本：1.0。一个用空格键或屏幕按钮玩的卡通钓鱼小游戏，使用 HTML、CSS、JavaScript 和 SVG；无需安装依赖，也不需要后端。

## 怎么玩

1. 轻按空格抛到近岸；按住空格看蓄力条和水上的落点标记，松开就甩竿。触屏可以按住屏幕按钮蓄力。鱼咬钩前，再按一次可收回空竿。
2. 近岸能钓鲫鱼。水草边和开阔水面都能钓到鲈鱼和金鲤：水草边通常咬钩较快，但鱼挣扎时更容易把线绷紧；开阔水面要多等一会儿，鱼线更容易松下来。
3. 咬钩后按空格收线，进度满了鱼就会上岸。线变红时先停手；金鲤挣扎后，鱼漂旁出现朝岸边的箭头，抓住机会能一次收两格。
4. 成功上岸才记入图鉴。抓准金鲤横移的时机并把它钓上岸，可以完成小挑战。图鉴和挑战保存在当前浏览器；浏览器禁止写入时，页面会显示提示。

## 怎么做的

| 文件 | 用途 |
| --- | --- |
| `index.html` | 网页结构、用 SVG 绘制的岸边和湖面、进度和张力提示、鱼图鉴 |
| `style.css` | 卡通配色、按钮和图鉴样式、窄屏布局 |
| `game.js` | 蓄力与落点、鱼群游动、咬钩和拉鱼、出水动画、图鉴和挑战存档 |
| `.nojekyll` | 让 GitHub Pages 原样发布静态文件 |

先把甩竿、等待、收线和鱼出水串起来，再加入鱼线张力和鱼的挣扎预警；之后把落点和鱼种做出区别，最后加入图鉴和金鲤挑战。游戏用 `requestAnimationFrame` 更新鱼的位置、鱼漂和竿线；每次松手才确定落点，鱼游到鱼饵附近才会咬钩。

## 本地运行与发布

- 本地运行：用桌面浏览器打开 `index.html`。
- GitHub Pages：仓库 **Settings → Pages**，选择 **Deploy from a branch**，选择包含源码的默认分支和 **`/ (root)`**，保存后等待 Pages 部署完成。
- 验收：使用未登录 GitHub 的浏览器打开 Pages 地址，确认能看到场景，CSS 和 JavaScript 正常加载，并试一次甩竿和空收。
